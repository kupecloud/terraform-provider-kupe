# kupe_app (Resource)

Manages a Kupe app: its name and deletion protection. Each place the app runs is a `kupe_app_environment`. Create and update wait until the platform has applied the app's settings, without waiting for its environments. To destroy the app, turn deletion protection off and apply, then destroy its environments before the app. No cluster is deleted.

## Example usage

```terraform
resource "kupe_app" "this" {
  name = "shop"

  # Deletion protection is on by default. To destroy the app, set this to
  # false and apply first.
  # deletion_protection = false
}
```

## Environments and deletion

Create each environment with `kupe_app_environment` and set its `app` to this resource's `name`. Terraform then creates the app before its environments and destroys the environments first.

Deletion protection is on by default for both resources. Set `deletion_protection = false` on the app and its environments, and apply, before you destroy them. The platform keeps an app while any environment remains, including one Terraform does not manage, and the provider never deletes environments it does not manage. Destroying an environment deletes its namespace and everything in it, and permanently deletes its own Vault entry (`apps/<app>/<environment>`), where its secrets are stored by default, unless a secret or another environment outside this one still uses it. If the entry cannot be deleted, or deleting it keeps failing for about five minutes, the environment is still destroyed and the entry is kept for you to delete with `kupe secret purge --path apps/APP/ENV`. The cluster and other Vault entries are kept.
