# kupe_app (Resource)

Manages a Kupe app's identity and deletion protection. Deploy each environment with `kupe_app_environment`. Create and update wait for the app's observed generation, independently of its environments. To destroy, turn protection off and apply first, then destroy the environments before the app. The cluster is kept.

## Example usage

```terraform
resource "kupe_app" "this" {
  name = "shop"

  # Protection defaults to true. Before destroy, set this to false and apply.
  # deletion_protection = false
}
```

## Environments and deletion

Use `kupe_app_environment` for each environment. Reference the app's `name` so Terraform creates the app first and destroys its environments first.

Protection defaults to true on both resources. Set `deletion_protection = false` and apply before destroying them. An app with any remaining environment is kept: Terraform does not authorise deletion of unmanaged environments. Destroying an environment deletes its namespace and everything in it. The cluster and Vault entries are kept.
