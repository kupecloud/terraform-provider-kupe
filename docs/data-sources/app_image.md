# kupe_app_image (Data Source)

Resolves an image tag or digest through the Kupe API to an immutable sha256 reference. Use `reference` as `kupe_app_environment.web.image`. Each read resolves again; a moving tag can change the next plan and deploy on apply. The provider sends no registry credentials.

## Example usage

```terraform
data "kupe_app_image" "web" {
  image = "ghcr.io/kupecloud/hello-kupe:1.5.1"
}

output "image_reference" {
  description = "Immutable image reference to use as kupe_app_environment.web.image."
  value       = data.kupe_app_image.web.reference
}
```

## Image resolution

The Kupe API resolves images from the tenant's container registry or a public registry approved by the platform. It checks linux/amd64 support and a numeric non-root user. The provider calls only the Kupe API and sends no registry credentials.

`reference` preserves the image index digest for a multi-platform image, or the manifest digest for a single-platform image. `platforms` contains the API's bounded summary as `os/architecture` or `os/architecture/variant`; the summary may omit supported platforms. `user` and `exposed_ports` describe linux/amd64.

Each read resolves again. Pin a version tag in production: a moving tag such as `latest` can change the next plan, and applying that plan deploys the new digest. A digest input keeps the image identity fixed.

The `image` diagnostic includes the API's image refusal code and message. A temporary image failure includes a retry hint; when the API supplies a numeric Retry-After, the hint gives the delay in seconds. Apps must be enabled on the platform to resolve an image.

When Apps are switched off, this data source fails during planning, including a destroy plan. To plan or destroy, replace `data.kupe_app_image` in your configuration with the image digest reference from Terraform state. Remove the data source block so Terraform no longer tries to resolve the image.

### Required

### Read-Only

- `exposed_ports` (List of Number) Exposed TCP port numbers for linux/amd64, as returned by the API.

- `user` (String) The image's numeric non-root user for linux/amd64, as checked by the platform.
